# Transformer Overload Monitoring System

## 📖 Overview

The Transformer Overload Monitoring System is an IoT-based project designed to monitor transformer load conditions in real time. It helps detect overload situations and alerts the user to prevent transformer damage, improving reliability and safety.

---

## ✨ Features

- Real-time transformer monitoring
- Overload detection
- LCD display for live readings
- Buzzer alert during overload
- Reliable and low-cost solution

---

## 🛠️ Components Used

- Arduino Uno
- Current Sensor
- Voltage Sensor
- LCD Display
- Buzzer
- Power Supply
- Transformer

---

## ⚙️ Working Principle

The current and voltage sensors continuously monitor the transformer. The Arduino processes the sensor values and compares them with predefined limits. If the transformer load exceeds the safe threshold, the system activates a buzzer and displays a warning message on the LCD.
