# Transformer Overload Monitoring System

## Overview

The Transformer Overload Monitoring System is an Arduino-based project developed to monitor transformer load conditions in real time. The system measures voltage and current using sensors and alerts the user whenever the transformer is overloaded. This helps improve transformer safety and reduces the risk of equipment damage.

---

## Features

- Real-time voltage monitoring
- Real-time current monitoring
- Overload detection
- LCD display for live readings
- Buzzer alarm during overload
- Relay-based load protection
- Low-cost and easy to implement

---

## Components Used

- Arduino Uno
- ACS712 Current Sensor
- Voltage Sensor Module
- 16x2 LCD Display
- Relay Module
- Buzzer
- Transformer
- Power Supply
- Connecting Wires

---

## Working Principle

The voltage sensor and ACS712 current sensor continuously measure the transformer parameters. Arduino Uno processes the sensor values and compares them with predefined threshold values. When an overload condition is detected, the buzzer sounds, the relay disconnects the load, and the LCD displays the warning message.
